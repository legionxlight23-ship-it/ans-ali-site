# Ans Ali, AI Filmmaker: website

Everything needed is in the repository ROOT (no folders):
- index.html  (the site, with every image and the CV built in)
- works.js    (films, blog, snapshots, contact; the manager exports this)
- showreel.mp4 and preview-*.mp4 (from ans-ali-videos.zip)

Keep your Google Drive "AI Films" folder shared as "Anyone with the link",
so film covers and full films keep loading.

To update later: export works.js from the manager, upload it to GitHub
(Add file > Upload files), commit. Vercel redeploys automatically.
